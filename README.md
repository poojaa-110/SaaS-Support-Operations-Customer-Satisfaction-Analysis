# SaaS Support Operations Analysis

## 📌 Project Overview

This project analyzes  100,000 support tickets to identify operational bottlenecks, improve ticket resolution efficiency, and understand customer satisfaction.

## 🎯 Business Problem

**How can a SaaS support team improve ticket resolution and customer satisfaction while reducing unresolved tickets?**

## 📊 Key KPIs

- Total Tickets: **100,000**
- Resolution Rate: **60.11%**
- Unresolved Tickets: **39.89%**
- Reopen Rate: **5.04%**
- Average Resolution Time: **45.01 hours**
- Median Resolution Time: **29.91 hours**
- P90 Resolution Time: **108.77 hours**
- Average CSAT: **3.20 / 5**
- CSAT Response Rate: **70.06%**

## 🔍 Key Insights

- Around **40% of tickets remain unresolved**, highlighting a significant backlog.
- Low-priority tickets have the longest resolution times.
- Mobile App and API Integration tickets show higher long-tail resolution times.
- Resolution time is relatively consistent across support channels and issue types.
- Around **29.53% of customers are dissatisfied**.
- Resolution time has **no statistically significant relationship with CSAT** in this dataset.
- SLA plans do not show a statistically significant difference in resolution time.
